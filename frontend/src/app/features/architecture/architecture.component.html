Architecture

What PROJECT NEXT is, how a cultural moment becomes a governed campaign, and what runs where. Written for anyone opening this system for the first time, not just engineers.

What this system does

PROJECT NEXT watches for cultural moments (a sports win, a viral trend, a news event) and turns a relevant one into a ready-to-review marketing campaign, in minutes instead of days. A signal comes in, twelve purpose-built AI agents sense it, check it against the brand, draft creative, and check that creative again for safety and voice. A human always makes the final call before anything is published. Nothing skips that approval, regardless of how confident the system is.

Autonomy levels — how much the system is trusted to do alone

Every opportunity is assigned one of three levels at the DECIDE stage. This is the system's core safety mechanism: risk, not confidence, decides how much happens without a person.

GREEN
Low risk, strong brand fit. Runs through creation and governance automatically; still waits for human approval before anything publishes.
AMBER
Some uncertainty. Same pipeline as GREEN, but flagged for closer review at the approval stage.
RED
Too risky to draft automatically. Creative generation is blocked outright in code and the opportunity is routed straight to a specialist.

Why it's built this way

  • One agent, one job. Every agent extends the same base class and only implements its own step. Changing what the Copy Agent does never risks breaking the Brand Guardian.
  • The orchestrator holds no business logic. It only sequences agents and enforces the risk gates — the "what" lives in the agents, the "when" lives in one place.
  • Brands are data, not code. Onboarding a new brand means adding rows to brands and brand_knowledge, not deploying new code.
  • One shared AI client. Every agent that needs a model calls the same OllamaService, so the model, host, and key are configured in exactly one place and can be swapped per role with no restart.
  • A human always signs off. Approval is a database record the Activation Agent checks for, not a UI convention — there's no code path that publishes without it.
